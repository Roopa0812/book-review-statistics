# 📚 Book Review Statistics

A comprehensive statistical analysis of a real-world books dataset using R. This project applies core concepts of statistical inference to explore patterns in book ratings and evaluate hypotheses using quantitative methods.

## 📖 Project Overview

The objective of this project is to analyze book ratings and related attributes through statistical techniques and draw meaningful conclusions from the data. The analysis demonstrates how statistical methods can be used to estimate population parameters, evaluate uncertainty, and test assumptions using real-world data.

The project focuses on applying fundamental statistical concepts rather than predictive modeling, making it an effective demonstration of statistical reasoning and data analysis skills.

---

## 🎯 Objectives

- Analyze the distribution of book ratings
- Estimate population parameters using sample statistics
- Construct confidence intervals for ratings and proportions
- Perform hypothesis testing on key metrics
- Demonstrate the Central Limit Theorem through simulation
- Visualize sampling distributions and statistical results

## 📈 Analysis Performed

### 1. Point Estimation
Estimated population parameters such as average book ratings and variability measures.

### 2. Confidence Intervals
Constructed 95% confidence intervals to quantify uncertainty around estimated parameters.

### 3. Hypothesis Testing
Tested statistical hypotheses regarding:
- Mean book ratings
- Proportion of highly rated books
- Average number of pages

### 4. Central Limit Theorem Simulation
Generated repeated random samples to demonstrate the behavior of sample means and validate the Central Limit Theorem.
